Montgomery Connected is a proof of concept for the city of Montgomery Alabama. 
It uses data from the open data platform provided by the city, in combination with
Scraped date from the web, to empower citizens with complex data insights near 
Their location.

Core libraries needed to run the files:
# lmstudio = local LLM provider (ibm/granite-3.1-8b)

pip install nicegui
pip install requests  
pip install beautifulsoup4
